# Telegram Running Bot (Календарь пробежек в Google Таблицах)

Бот для бегового чата Telegram, который отслеживает отчеты участников по хэштегам и автоматически ведет календарь пробежек на каждый день месяца в Google Таблицах.

---

## 🏃 Как работает бот

1. Участник чата присылает сообщение с двумя хэштегами:
   - `#япобегал` (основной тег, без учета регистра).
   - `#??км` (дистанция: `#5км`, `#10.5км`, `#21,1км`, `#42км` и т.д.).
   *Пример сообщения:*
   > Утренняя десяточка по набережной! ☀️ #япобегал #10.5км
2. Бот перехватывает сообщение, извлекает дистанцию `10.5`.
3. Находит (или создает) вкладку текущего месяца (например, **`Октябрь 26`**).
4. Находит строку участника или добавляет нового бегуна в календарь.
5. Записывает километраж в столбец сегодняшнего числа.
   - Если за день было несколько пробежек — дистанции суммируются (например, 5 + 3 = 8 км).
   - Столбцы **Итого (км)** и **Пробежек** рассчитываются автоматически по формулам.
6. Бот ставит реакцию 🏃 или 👍 на сообщение в чате.

---

## 📁 Структура проекта

- **`bot.py`** — основной скрипт бота (`aiogram 3` + `gspread`).
- **`.env`** — файл конфигурации (токен бота, ссылка на Google Таблицу).
- **`credentials.json`** — ключ авторизации сервисного аккаунта Google Cloud.
- **`TZ.md`** — утвержденное техническое задание.
- **`GOOGLE_SETUP.md`** — инструкция по настройке Google Cloud Console.
- **`run.bat`** — запуск бота в 1 клик на Windows.

---

## 🚀 Запуск бота

### Способ 1: Дважды кликнуть по файлу `run.bat` в папке проекта.
### Способ 2: Через терминал:
```powershell
cd telegram_tag_bot
py -3.12 bot.py
```

---

## ⚙️ Настройки в Telegram
- Убедитесь, что бот добавлен в беговой чат.
- В [@BotFather](https://t.me/BotFather) должен быть отключен Privacy Mode (`/setprivacy` -> выберите бота -> **`Disable`**), либо бот должен быть назначен **Администратором** чата.
